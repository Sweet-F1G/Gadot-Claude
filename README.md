# claude-godot

Плагин Claude Code для открытого редактора Godot 4. Восемь инструментов: статус, дерево сцены, один узел, одно свойство, снимок вьюпорта, запуск, лог игры и пересканирование файлов. Сотни тулов в контекст не попадают, ответы — компактный JSON.

Мост работает только с редактором на этой машине. К собранной игре он не подключается.

## Что нужно

- Godot 4.2 или новее (проверено на 4.2.2 и 4.7.2)
- Node.js 18 или новее (`node` в `PATH`)
- Claude Code

## Установка плагина

В Claude Code, из любой папки:

```text
/plugin marketplace add Sweet-F1G/Gadot-Claude
/plugin install claude-godot@claude-godot
```

Если нет SSH-ключа для GitHub, добавьте магазин по HTTPS: `/plugin marketplace add https://github.com/Sweet-F1G/Gadot-Claude.git`.

Проверка из клона репозитория, без магазина:

```text
claude --plugin-dir ./plugins/claude-godot
```

## Подключение проекта

Открывайте Claude в папке игры или в репозитории, где игра лежит на один-два уровня глубже. Сервер ищет `project.godot` вверх по папкам и на два уровня вниз. Если проектов несколько, укажите нужный в переменной `GODOT_PROJECT`.

Проще всего попросить Claude «проверь связь с Godot»: `godot_status` вернёт готовую команду установки с полными путями. Вручную, из клона репозитория:

```text
node plugins/claude-godot/scripts/install-addon.mjs C:\path\to\your-game
```

Скрипт заменяет `addons/claude_godot` в игре, включает аддон в `project.godot` и добавляет `.claude-godot/` в `.gitignore`. Флаг `--no-enable` оставляет включение вручную. Лучше запускать при закрытом редакторе: открытый редактор может перезаписать `project.godot`.

Перезапустите редактор. В выводе Godot появится `Claude Godot 0.2.0 listening on 127.0.0.1:8787`. Если порт занят, берётся следующий до 8796.

## Инструменты

| Инструмент | Зачем |
| --- | --- |
| `godot_status` | Версии, проект, открытые сцены, идёт ли игра |
| `godot_scene_tree` | Иерархия открытой сцены, вложенные сцены не раскрываются |
| `godot_node` | Скрипт, дети и свойства, отличные от значений по умолчанию |
| `godot_set_property` | Одно свойство через undo редактора, по желанию с сохранением |
| `godot_screenshot` | Вьюпорт 2D или 3D, до 960 px в ширину; тяжёлый PNG уходит в JPEG |
| `godot_play` | `play`, `main` или `stop` |
| `godot_log` | Хвост `user://logs/godot.log` последнего запуска, можно только ошибки |
| `godot_refresh` | Пересканировать файлы, открыть или перечитать сцену с диска |

Скрипты, сцены и `project.godot` Claude правит как файлы. Мост нужен там, где файл не показывает правду: живое дерево, картинка редактора, запуск и лог.

`godot_refresh` со сценой, которая уже открыта, перечитывает её с диска. Несохранённые изменения в этой сцене пропадают.

Если плагин обновился, а аддон в игре старый, `godot_status` вернёт предупреждение с командой переустановки.

## Тесты

```text
node --test plugins/claude-godot/test/mcp.test.mjs plugins/claude-godot/test/godot.e2e.test.mjs
```

Тест в настоящем редакторе запускается, если `GODOT_BIN` указывает на консольный exe Godot 4. Он поднимает редактор без окна и проверяет все инструменты, кроме снимка.

## Безопасность

Слушает только `127.0.0.1`. Каждое соединение сверяет токен из `.claude-godot/session.json`. Файл перезаписывается при старте редактора и удаляется при выходе. Поле хоста в сессии не читается: MCP-сервер всегда ходит на localhost. Снимок читается только изнутри папки проекта. Свойства-объекты и вызовы методов через мост не проходят.

Токен лежит в папке проекта. Её не коммитьте, установщик добавляет её в `.gitignore`.
